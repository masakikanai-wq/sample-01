# ModernBiz Landing Page

モダンビジネスソリューションのランディングページです。

## 概要

このプロジェクトは、モダンなビジネスソリューションを提供する企業のためのレスポンシブなランディングページです。HTML5、CSS3、Vanilla JavaScriptを使用して作成されています。

## 機能

- **レスポンシブデザイン**: デスクトップ、タブレット、モバイルに対応
- **スムーズスクロール**: ナビゲーションリンクでページ内の滑らかな移動
- **フェードインアニメーション**: スクロール時の要素の表示アニメーション
- **FAQアコーディオン**: よくある質問セクション
- **モダンUI**: 洗練されたデザインとホバーエフェクト

## ファイル構成

```
wireframe-landing/

├── css/

├── js/
│   └── script.js       # JavaScript ファイル
├── images/             # 画像ファイル用ディレクトリ
├── README.md           # このファイル

```

## セクション

1. **Hero Section**: メインビジュアルとキャッチコピー
2. **Features**: プラットフォームの主な機能
3. **Company**: 会社概要
4. **Service**: 提供サービス一覧
5. **Case**: 導入事例
6. **News**: 最新ニュース
7. **Career**: 採用情報
8. **Contact**: お問い合わせ
9. **FAQ**: よくある質問

## 開発

### ローカル開発環境

1. プロジェクトをクローンまたはダウンロード
2. Webサーバーでindex.htmlを開く（Live Serverなど）
3. ブラウザで確認

### カスタマイズ

- **色**: CSS変数で主要な色を管理
- **フォント**: Google Fontsで簡単に変更可能
- **レイアウト**: CSS GridとFlexboxでレスポンシブ対応
